# 归位 Guiwei

让文件有位置，让事情有安排。

归位是基于 [Übersicht](https://tracesof.net/uebersicht/) 的 Mac 桌面工作台：左侧工作资料，右侧个人项目，中间四象限待办，下方截止日期月历。适合摄影、剪辑、设计、自由职业和同时推进多个项目的个人。

## 功能

- 桌面「工作 / 我的项目」分区标题：把真实 Finder 文件夹拖到对应区域，保留原生打开行为。
- 快速记事、待分类、四象限分类、完成、删除及撤销最近一次删除。
- 可选截止日期和时间；月历在对应日期显示任务，并沿用象限颜色。
- 查看已完成任务、截止时间明细和导出 JSON 备份。
- launchd 后台运行及登录启动，不依赖 ChatGPT / Codex 保持打开。
- 服务启动后自动恢复组件，每 10 秒检查一次。

分区是视觉指引，不会自动移动或归档文件。备忘录 / 提醒事项同步尚未实现。

## 安装

需要 macOS、Python 3.10+ 和 Übersicht。桌面模式目前只在单显示器环境验证。

1. 从 [Übersicht 官网](https://tracesof.net/uebersicht/) 安装并启动应用。
2. 从 [Python 官网](https://www.python.org/downloads/macos/) 安装 Python，或使用已有的 Python 3.10+。
3. 下载仓库 ZIP 并解压到准备长期保留的目录，或克隆仓库。
4. 在终端进入项目目录并执行：

```sh
python3 scripts/install.py
```

首次启动如系统询问桌面文件访问权限，请允许。等待约 10 秒，组件应显示在桌面；必要时在 Übersicht 菜单选择 **Refresh All Widgets**。

安装器会添加两个登录启动项和两个 `guiwei-` 前缀组件。重复安装会更新本项目组件，不会清空任务。项目目录被移动后需要重新运行安装命令。

若正在使用旧版「桌面工作台」，先导出备份并停用旧版（同一个 18743 端口不能同时运行两个版本），再安装本项目。旧版任务不会自动迁移；可在停止服务后把旧 `tasks.json` 复制到下述数据目录。

## 使用

1. 把工作文件夹放在左侧，把个人项目文件夹放在右侧；不要让图标被中央面板覆盖。
2. 在上方输入事项，选择分类，可选填截止时间，然后点击「记下」。
3. 用任务旁的分类菜单调整象限；勾选完成，点击 × 删除，误删可立即撤销。
4. 下方月历显示当月日期，支持切换月份及返回本月。点击日历中的任务可修改截止时间。
5. 「导出任务备份」保存 JSON；重要任务请定期备份。

日期按当前实现的 **Asia/Shanghai** 时区计算。任务截止时间保存为无时区的本地日期时间，跨时区使用需自行确认。

## 数据与隐私

所有任务保存在本机 `~/Library/Application Support/Guiwei/tasks.json`，不上传云端，无账号、埋点或外部网络资源。仓库不包含个人任务、桌面截图或壁纸。桌面文件夹名称仅由本机服务读取。

本地服务仅监听 `127.0.0.1:18743`，检查写入请求来源，但没有用户认证。适用于个人电脑；不要把端口暴露到公网或共享网络。

## 自定义布局

- `widgets/desktop-workspace.jsx` 的 `className`：调整面板的 `top / left / width / height`。
- `widgets/desktop-labels.jsx`：修改分区名称和位置。
- `index.html`：调整颜色、字号、四象限和日历布局。

修改组件后重新执行安装器；修改页面文件后刷新组件即可。壁纸由 macOS 自行设置，项目不附带壁纸。

## 故障排查

- **空白 / 正在启动**：先运行 `python3 server.py` 看是否报端口占用或 Python 错误，日志在数据目录 `error.log`。不要和已运行的后台服务同时启动。
- **不能输入**：确保 Übersicht 正在运行并刷新组件；点击输入框会激活 Übersicht。交互依赖其 WebKit 消息接口，不同版本可能需要适配。
- **文件夹打不开**：确认图标在中央面板范围之外，并检查系统桌面文件权限。
- **关闭聊天后消失**：检查 `launchctl print gui/$(id -u)/local.guiwei.server`，用安装器重新安装。
- **多显示器 / 不同缩放比例**：先调整 JSX 百分比布局；当前没有自动适配全部屏幕的承诺。

## 卸载

```sh
python3 scripts/uninstall.py
```

卸载保留数据和项目源文件。可在确认备份后自行移除数据目录。

## 开发

后端只用 Python 标准库，前端是原生 HTML/CSS/JavaScript，桌面组件使用 Übersicht JSX。

```sh
python3 server.py
# 浏览器打开 http://127.0.0.1:18743/
python3 -m unittest discover -s tests -v
```

测试使用临时数据目录，不会改动真实任务。`GUIWEI_DATA_DIR` 可覆盖测试数据位置；`GUIWEI_PORT` 可用于后端测试，桌面组件及来源校验仍固定使用 18743。
